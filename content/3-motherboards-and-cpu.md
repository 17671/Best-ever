## THE MOTHERBOARD

- Its structure is a sandwich, consisting of two outer pieces, made from non-conductive materials and the inside piece, a conductive material.
- Non-conductive materials resist the flow of electricity.
- Conductive materials have little to no resistance to the flow of electricity.
- Engineers first decide where the etched wires should appear on the motherboard.
- This decision is based on electrical engineering principles and the needs of components that will be used on the circuit board.

## COMPONENTS ON A MOTHERBOARD

- The chip refers to a large-scale integrated circuit that contains the logic to store, retrieve, transmit and process information.
- Examples of chips we learned so far include the CPU, the Clock, and memory chips.
- The most important memory chip on the motherboard is the ROM chips that contains the main basic input/output system (BIOS). They offer a guideline, telling the computer how to operate.
  - For example, a video adapter typically contains a ROM chip with the instructions to operate the video adapter itself.
- The main BIOS stores the first set of instructions that are read when a computer is powered on. These bring all the other components such as the motherboard, keyboard, mouse and monitor alive.
  - It is also in charge of loading the Operating System (OS) from the disk.

## EXPANSION SLOTS

- They are used to enhance features of a motherboard. Features which aren’t built-in the motherboard, meaning native to the motherboard, can be added by inserting a circuit board that contains the set features into an expansion slot.
- Connectors inside expansion slots link to the motherboard, allowing the flow of information.
- These are commonly manufactured by Intel and come in the form of:
  - **Industry Standard Architecture (ISA)**
    - The ISA expansion slot, little by little, becomes outdated, being found on older computers.
  - **Peripheral Component Interconnect (PCI)**
    - A PCI expansion slot transfers information much quicker than ISA, which is the reason nowadays computers use a PCI expansion slot.
  - **Accelerated Graphics Port (AGP)**
    - They are designed to enhance video information, as it requires much more information to be transported onto a motherboard than any other type of information.
    - The AGP expansion slot must be used along with the appropriate expansion circuit board to maintain quality video reproduction on computer screens.

## PORTS

- They are used to link the motherboard to external devices. Ports can be dedicated for a particular device such as a keyboard and mouse. Other ports are used to connect printers and monitors.
- The most common ports include the universal serial bus (USB), Small Computer System Interface (SCSI) and the A-D port.
- The serial port, called the COM port, sends and receives information between the motherboard and external devices, one bit (of information) at a time. In contrast, a parallel port transports information 1 byte at a time.
- The USB port notifies the OS when the status of the port changes such as when a device is removed or inserted into a port.
  - It can also provide power to devices that are external to the computer. This way, a modem gets its power from the USB port, removing the need of an external source like an outlet.
- The USB hub is an expandable feature where multiple USB devices are directly connected to the USB port.
  - As with any USB device, the hub can be powered by the USB port. This means that an almost endless number of USB devices can be connected to a computer.
- Thus, the USB port is not only replacing the serial and parallel ports but also dedicated ports such as those used for the keyboard, mouse and video displays.
- SCSI devices have two SCSI ports of their own.
  - One port is used to connect the device to the SCSI port on the motherboard, while the other is used to connect to the SCSI port of another device, forming a chain.
  - As described in the previous chapter, each port has a unique address inside the computer.
  - All devices connected to the chain are accessed by using the SCSI port address.
  - Logic built into the circuitry lets the system know which SCSI device is to receive the information.
- The A-D port converts an analog signal generated by a device such as a joystick to a digital signal.
  - An analog signal is similar to the signal generated by your voice, in that the signal contains different values. For example, your voice produces various values called frequencies as you speak.
  - A digital signal has only two values represented by a zero or a one.
  - A joystick generates many values as it’s moved; the A-D port converts these signals into zeros and ones. Its use expands to the measurement instrumentation used even in hospitals.

## POWER SUPPLY

- The power supply receives various voltages from the wall socket ranging from 110 AC to 220 AC depending where you live. Computers come with a power supply rated to handle all the features that are built into the motherboard and to power most expansion circuits.
- It, along with its circuitry, steps down the voltage and converts power from alternating current to direct current.
- Examples:
  - The disk drives require 12 volts.
  - The processor and memory use 3.3 volts.
  - Other components use 5 volts.
- Component manufacturers design components that require a set minimum voltage to operate in order to conserve energy. This has the following advantages:
  1. It makes the computer energy efficient.
  2. Reduces heat generated by electricity.
  3. Extends the life of components.
- Reduced power allows designers to build more powerful components because of the reduction in heat. An example is the reduction in the voltage used by the Pentium CPU, specifically from 5 volts to 3 volts.
- Voltage regulating circuits or Voltage Regulating Modules (VRMs) are integrated into the power supply to supply various voltages to each component based on the manufacturer’s specifications.
- Nominal voltage is the voltage that is received from the power cord.
- A word of caution: The motherboard will be damaged if the nominal voltage is higher than the voltage the power supply is rated for.
  - No damage is caused if the power cord supplies 110 volts and the power supply is set for 220 volts, however, it is likely the computer will not function properly.
- The nominal voltage coming from the Utility Company supplies electricity to the wall socket within a specified operating voltage, usually between 90 to 135 volts, averaging to 110 volts.
  - For this reason, the VRM is designed to keep voltage within the acceptable limit of tolerance the components within are capable of functioning.
- The VRM itself also needs to be supplied within an acceptable range to properly distribute the electricity to the internal components.

## CHARACTERISTICS OF A MOTHERBOARD

- A motherboard defines a computer. When choosing a computer you are actually making a decision based on the characteristics of the motherboard (unless your choice is based on the color of the box).
- Although motherboards are manufactured without a processor and other chips, they are designed to support a particular processor and group of chips, collectively known as the chipset.
- Even if a processor could fit on a motherboard, it doesn’t mean that the motherboard supports the processor.
  - One of the common designs of a processor socket is Slot 1, designed to accept the Pentium II, Pentium III and the Celeron CPUs.

## CHIPSETS

- A chipset consists of anywhere from one to three chips depending on the manufacturer’s design.
  - It can be identified by visiting the motherboard manufacturer’s website and using either the make and model of the motherboard or the chipset code to look up the chipset information.
- Chips support features of processors, one example being the transfer of information over the bus to the processor and memory.
  - As mentioned in Chapter 2, memory cache is used to store a copy of previously used instructions and data for later use.
- The crucial role of the chips is that they determine if an instruction or data is to be retrieved from the main memory or from the memory cache.
- It manages the transfer of information at different speeds on the motherboard, as some components work faster than others (see Chapter 2).
  - As with memory cache, the chipset must be designed with sufficient buffers to effectively handle the transfer required by the motherboard.
- A chipset is designed to work with one family of processors, meaning a generation of processors made by the same manufacturer. Some will also work with compatible processors.
- The chipsets determine if the speed of the buses on the motherboard is coordinated or works independently of the memory bus.
  - A synchronous motherboard example: the speed of the PCI bus is typically half the speed of the memory bus. For this reason, the chipset uses a factor of 2 to adjust the speed of the PCI bus.
  - Where the speeds of each bus are independent of each other, it is referred to as an asynchronous motherboard.

## THE BUS

- A set of etched wires on the motherboard used to transport information among components.
  - Information flows in both directions along a bus, such as from and to the CPU and memory.
  - Connecting components to more than one bus enables them to become multifaceted in that information can flow using more than one pathway on the motherboard.
- A port is a special type of bus because it connects one external device with the motherboard.
- There are 6 main types of buses used in computers: AGP, cache, local input/output, memory, processor and standard input/output.
  1. The AGP transports display information quickly between the processor and the video adapter card, particularly useful in graphics-intense applications such as video games.
  2. The cache bus carries information between the processor and the cache memory at speeds equal to the internal processing of the processor.
  3. The local input/output keeps communication between the processor and input devices and input/output devices. They include disk drives, CD drives, video and network adapters.
  4. The memory bus connects the main memory with the processor although some motherboards combine the function of the memory bus with that of the processor bus.
- The processor bus is similar to the local input/output bus except it connects to the expansion slots integrated on the motherboard.
- The width of a bus is measured in bits that can be transported at one time.
  - Each bit is carried over one etched wire on the data segment of the bus.
  - The PCI bus found in new personal computers is 32 bits wide.
- The best throughput between data flowing over the bus and into the processor is achieved when the width of the data segment of the bus equals the data pins of the processor.
- The bus speed is determined by the bus clock speed, which is measured in MHz.
  - This is the number of clock cycles per second.
  - One set of bits travels over the bus in one clock cycle and the number of bits in a set is equal to the width of the bus.
- The product of multiplying the number of clock cycles by the width of the bus is the maximum number of bits of information that can be carried across the bus per second.
