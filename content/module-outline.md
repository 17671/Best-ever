# Part 1: Hardware & Data

---

### Chapter 1.1: Number Systems and Data

📄 **File:** `1-1-number-systems-and-data.md`

#### Chapter Overview

> This chapter introduces what a computer is and how it works, from the basic workflow of input, processing, storage, and output down to the binary data it uses. You'll study number systems and data storage.

#### Learning Outcomes

By the end of this chapter, you will be able to:

- Define a computer, describe its basic workflow, and distinguish between types of computers.
- Convert between binary, decimal, and hexadecimal number systems.
- Explain how numbers, text, images, audio, and video are stored as binary data.
- Distinguish between primary (RAM) and secondary storage (SSD/HDD).

#### Material

| Stage | Topics |
| :--- | :--- |
| **Stage 1: Computers and Data** | • Definition of a Computer<br>• The Basic Workflow of a Computer (input, processing, storage, output)<br>• Different Types of Computers |
| **Stage 2: Number Systems** | • Number System Overview<br>• Binary Number System<br>• Decimal to Binary and Binary to Decimal<br>• Hexadecimal to Binary and Binary to Hexadecimal<br>• Hexadecimal to Decimal and Decimal to Hexadecimal |
| **Stage 3: Data Storage** | • Definition<br>• How Does Data Storage Work<br>• Representing Data in Binary (numbers, text, images, audio, video)<br>• Types of Data Storage (primary and secondary)<br>• Data Storage Devices (HDD, SSD, USB drives) |
| **Stage 4: Chapter Exercise** | — |

### Chapter 1.2: Hardware and the Von Neumann Model

📄 **File:** `1-2-hardware-and-von-neumann.md`

#### Chapter Overview

> This chapter covers the physical components of a computer and how they execute instructions using the Von Neumann model. It covers the physical components that make up a computer and how a program runs.

#### Learning Outcomes

By the end of this chapter, you will be able to:

- Describe the Von Neumann model and its main components.
- Identify input, output, and internal hardware components, and explain the difference between internal and external hardware.
- Explain how hardware components work together to execute a program.

#### Material

| Stage | Topics |
| :--- | :--- |
| **Stage 1: Von Neumann Model** | • Definition<br>• Process (fetch-decode-execute)<br>• Components (1): CPU (control unit and ALU)<br>• Components (2): Memory, Input, and Output |
| **Stage 2: Computer Hardware** | • Hardware Definition<br>• Input Devices: Mouse, Keyboard, Microphone, Camera, Touchpad<br>• Output Devices: Monitor, Printer, Speaker<br>• Internal Hardware: Motherboard, CPU, RAM, RAM vs ROM, Graphics Card, Power Supply<br>• Ports and External Storage: USB, Memory Card |
| **Stage 3: Program Execution** | • Definition<br>• How Program Execution Works (from stored program to running task) |
| **Stage 4: Chapter Exercise** | — |

### Chapter 2.1: Network and Internet Basics

📄 **File:** `2-1-network-and-internet-basics.md`

#### Chapter Overview

> A computer network connects two or more computers so they can share data and resources. This chapter covers the parts of a network, the types of network, and how the internet works.

#### Learning Outcomes

By the end of this chapter, you will be able to:

- Define a computer network and explain why computers are networked.
- Identify the common parts of a network and describe what each does.
- Distinguish between LAN and WAN.
- Explain how the internet delivers data using TCP/IP, IP addresses, and domain names.
